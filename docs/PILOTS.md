# Pilot sequence

1. **AtlasHub Editions** — content + library + WebReader + theme; no required auth/commerce.
2. **EspelhoMeu** — clean scaffold; validate project generation and branding.
3. **MyTrainX** — auth + programs + community + Trainer companion + commerce.
4. **LIA / LeveLab** — companion, memory, safety, check-ins and human handoff.
5. **MyPets** — production-grade campaign commerce, entitlements and rich media reader.

MyPets is an extraction source from day one, but should not be the first migration target.
